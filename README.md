## 🎯 Sobre o projeto

Programa em Python que realiza uma pesquisa de satisfação de atendimento com **50 entrevistados**. Para cada um, pede nome, idade e opinião. No final, mostra quantas respostas foram **Excelente** e quantas foram **Ruim**.

## ⭐ Opções de opinião

| Código | Opinião |
|---|---|
| 1 | 😄 Excelente |
| 2 | 🙂 Bom |
| 3 | 😞 Ruim |

## 🧠 Conceitos utilizados

- 🔁 Estrutura de repetição (`for` com `range`)
- 🔀 Estruturas de decisão (`if` / `elif`)
- 🔢 Contadores
- ⌨️ Entrada de dados com `input()`

## ▶️ Como executar

```bash
python app.py
```
